# 🛒 Ecommerce Store

A full-stack Ecommerce Web Application built to provide an online shopping experience with a user-friendly interface and backend integration.

## 📌 About the Project

Ecommerce Store is a web-based shopping application developed using modern web technologies. It aims to make online shopping simple, convenient, and accessible through an interactive user interface.

## ✨ Features

- Responsive and user-friendly interface
- Product browsing and shopping experience
- Organized frontend and backend architecture
- API integration
- Modern React-based frontend
- Backend server for application functionality

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/ShagunGangwar21/ecommerce-store.git
```

### 2. Navigate to the project directory

```bash
cd ecommerce-store
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the frontend development server

```bash
npm run dev
```

### 5. Run the backend

Navigate to the server folder:

```bash
cd server
npm install
```

Run the backend using the start command configured in the server's `package.json`.
